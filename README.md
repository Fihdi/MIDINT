# 6hp MIDI Interface (work in progress)
![](https://github.com/Fihdi/MIDINT/blob/main/MIDINT-Front.png?raw=true)

MIDINT is an eight channel MIDI interface in 6hp. Take a standard DIN-5 MIDI cable connected to your favorite DAW or MIDI gear and control up to eight Gate, Trigger and CV channels. Trimmers on the back of the module allow for precise V/Oct tuning. The CV outputs can thus control oscillators and filters without the need for an external quantizer.

Selecting a channel with the "SELECT" encoder and pressing it will switch it between a trigger or gate output.

# Features

- 4 Gate or Trigger outputs
- 4 CV outputs (Can also be used as Gate or Trigger outputs)
- Extension of up to three modules.

# Extension 

Its possible to daisy-chain up to three extension modules to one main module and expand your interface system to a maximum of 32 Gate/Trigger/CV channels. To connect extension module(s) to a main module:

WARNING: Do NOT connect main modules together!

- Turn your modular synthesizer off
- Take an extension module(s) and change the jumper from "MAIN" to "EXT".
- Add jumpers to "EXT1" and "EXT2" to configure the MIDI channels (see table below)
- Connect the extension module(s) to a main module or another extension module in the chain with a wire underneath the power connector.
- Connect each module(s) to power
- Turn your modular synthesizer on
